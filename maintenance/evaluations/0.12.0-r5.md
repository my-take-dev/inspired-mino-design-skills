## PR #11の評価ファイル形式検査修正（2026-09-16）

[レビュー指摘](https://github.com/my-take-dev/mino-drive-inspired-design-skills-dev/pull/11#discussion_r4025695213)を、head `56394cef0b64e7035927424389105069a50b8f83`で再現した。使い捨てfixtureでactive case、oracle JSON、oracle MarkdownをそれぞれCRLFへ変更しても、修正前validatorは3種類ともexit 0 / 992 checks / errors 0を返した。
