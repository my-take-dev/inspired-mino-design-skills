# 打合せ用：検索サービスと画面の品質優先案

受付担当の業務中断を減らすため、第一優先の候補を「ピーク時に検索を始めてから、結果を画面で使えるまでの待ち時間の短縮」とする。根拠はピーク時の検索待ちが長いという観測。検索サービス単体の高速化だけでなく、画面まで含む業務上の待ち時間で比較する。これは提案であり、採用済みの方針ではない。

検索結果の内容と閲覧権限の維持は、速度と引き換えに緩めない制約とする。運用費の抑制は副次候補だが、許容増分が不明なため、応答性との優先関係は未決とする。許容待ち時間も未定であり、数値目標は置かない。

比較対象は、現状維持、遅延箇所を絞った最小修正、サービスと画面を段階的に改善する案とする。現状維持には待ち時間を改善する根拠がない。最小修正は遅延が局所に集中していれば候補になる。段階改善は複数箇所が待ち時間に寄与していれば候補になるが、各段階の検証・運用負担との比較が必要になる。遅延箇所が未確認のため、構造上の原因や技術方式は断定できない。

採用判断の前に、ピーク時の検索開始から画面での結果利用までを計測し、サービス側と画面側の内訳を確認する。結果内容・閲覧権限を維持できること、担当者が決める許容待ち時間と許容費用増分を満たすことを比較条件にする。基準を決める業務・費用の判断責任者と、計測担当は未確認のため、打合せで特定する。計測結果と費用見積りで、優先案と候補を再評価する。

現時点では条件付きの品質比較案。計測と改善検証は未実行であり、採用判断は未決。
